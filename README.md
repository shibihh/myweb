# 🚀 Shibihhh - Personal Portfolio & Web Animation Hub

A modern, high-performance personal portfolio website for **Shibihhh** (B.Tech Undergrad & Creative Web Developer).

Built with zero external software dependencies—powered by pure **HTML5 Canvas, Modern CSS3 Glassmorphism, Vanilla ES6+ JavaScript, and the Web Audio API**.

---

## 🌟 Key Features

1. **Interactive Fullscreen Canvas Constellation Engine (`js/particles.js`)**:
   - Dynamic particle constellation that reacts to mouse velocity and gravitational pull.
   - Mouse attraction and repulsion physics modes.
   - Click-to-shockwave and burst particle effects.

2. **Web Animation Lab / Sandbox**:
   - Live on-page controls for visitors to tweak particle density, velocity, connection distances, and cyberpunk color themes (Cyan, Violet, Emerald, Amber, Cyber Pink).

3. **Personal Data Matrix & Developer Terminal (`js/animations.js`)**:
   - Interactive hacker terminal with runnable commands: `bio`, `data`, `skills`, `projects`, `contact`, `clear`, and `whoami`.
   - Quick command chips for instant one-click execution.
   - B.Tech academic specs and credentials matrix.

4. **Web Audio Synthesizer**:
   - Zero-asset synthesized sci-fi audio effects generated directly via the browser's Web Audio API.
   - Interactive audio toggle in the navigation header.

5. **3D Tilt & Specular Sheen Cards**:
   - Realistic 3D card tilt that follows the cursor with dynamic specular glare.

6. **Fully Mobile-Friendly & Responsive**:
   - Adaptive layouts that look sharp on mobile phones, tablets, laptops, and ultra-wide screens.

## 🖥️ How to Run Locally

No installations (Node.js, npm, or Python) are required!

1. Open File Explorer to `c:\Users\user\Downloads\webdata`.
2. Double-click **`index.html`** to open it directly in Google Chrome, Microsoft Edge, Mozilla Firefox, or Brave.

## 🌐 How to Deploy for Free

You can host this website online in less than 2 minutes:

### Option 1: GitHub Pages
1. Create a repository on GitHub named `shibihhh.github.io`.
2. Push or upload the files from this folder (`index.html`, `styles.css`, `js/`, `README.md`).
3. Your site will immediately be live at `https://shibihhh.github.io`!

### Option 2: Netlify / Vercel
- Drag and drop the `webdata` folder directly onto [Netlify Drop](https://app.netlify.com/drop) or Vercel for an instant live URL.
